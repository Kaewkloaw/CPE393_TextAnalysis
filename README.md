## 📄 Course Description
<p style="text-align: justify; line-height: 1.6;">
  <strong>CPE 393 Text Analytics</strong> is a delightful course offered by the <strong>Department of Computer Engineering, KMUTT</strong>.
  It provides an introduction to the methodologies for processing textual data and extracting valuable insights from unstructured text.
  Students will gain foundational knowledge and practical skills essential for working with text-based data in various applications.🌸
</p>
